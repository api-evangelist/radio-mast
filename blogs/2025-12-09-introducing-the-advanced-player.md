Radio Mast launched the Advanced Player, a customizable widget that lets listeners tune in via browser or install as a mobile app using progressive web app technology. It includes track history, social sharing, multiple stream support, and HLS audio for better mobile performance, at no extra cost to Streaming Network customers.
